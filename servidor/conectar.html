📱 Conectar o celular

Aponte a câmera do celular para o QR Code, ou digite no Chrome:
  1. O celular precisa estar no mesmo Wi-Fi do computador (ou no roteador do celular).
  2. Vai aparecer "Sua conexão não é particular": toque em Avançado → Continuar. É normal: o certificado é deste computador.
  3. Se não abrir, confira se o Windows bloqueou o Python no firewall (permitir em redes privadas).
